# 🏥 HealthRise Dashboard Analysis

---

# 📌 Project Overview

A data-driven healthcare analytics solution designed to deliver clear insights into claims processing, patient classification, and operational performance. This dashboard supports decision-making by highlighting high-risk accounts, financial outcomes, and workflow efficiency across the organization.

---

# 🎯 Purpose

To provide a centralized analytics platform that enables healthcare teams to monitor claims performance, optimize resolution workflows, and improve financial recovery using dynamic and interactive visualizations.

---

# 📊 Key Dashboard Components

## 1️⃣ Claims Performance Metrics

Comprehensive financial and risk insights:

- **Total Accounts:** 28,000  
- **High-Risk Open Accounts:** 2,000  
- **Total Denied Amount:** $661.95M  
- **Total Recovery Amount:** $302.83M  
- **Recovery Rate:** 43.38%

---

## 2️⃣ Patient Class Analysis

Breakdown of patient categories for operational planning:

- **Inpatient:** 34.97%  
- **Outpatient:** 44.68%  
- **Emergency:** 20.05%

---

## 3️⃣ Resolution Dynamics

Workflow efficiency and claim lifecycle insights:

- **Average Resolution Time:** 101.60 days  
- **Minimum Resolution Time:** 48 days  
- **Median Resolution Time:** 92 days
