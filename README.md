# 📊 Power BI Dashboards

A collection of **Power BI dashboards** built for business intelligence, analytics, and performance reporting.  
Each project includes a `.pbix` file that can be opened directly in **Power BI Desktop**.

---

# 📁 Dashboards Included

## 🏥 HealthRise Dashboard
Interactive healthcare analytics dashboard for monitoring performance and insights.

## 🚚 Supply Chain Operations Dashboard
Dashboard focused on operational efficiency, logistics, and supply chain KPIs.

## 🌍 Migration Tracker Dashboard
Tracks migration trends and related analytical insights through interactive visuals.

## 🧾 Medicare Claims & Eligibility Dashboard
Healthcare claims and eligibility reporting dashboard with detailed analytics.

## ❄️ SnowRoute – Supply Chain Dashboard
Supply chain monitoring and reporting dashboard with operational tracking.

---

# 🛠️ Tools & Technologies Used

### • Power BI Desktop
Used for dashboard development and report creation.

### • Power Query
Used for data transformation and ETL processes.

### • DAX (Data Analysis Expressions)
Used for calculated measures, KPIs, and custom analytics.

### • Microsoft Excel
Used for data cleaning and preprocessing.

---

# 🚀 How to View the Dashboards

## Step 1
Download any `.pbix` file from the repository.

## Step 2
Open the file in **Power BI Desktop**.

## Step 3
Explore the dashboard using:
- Filters
- Slicers
- Interactive Charts
- Navigation Panels
